## Failure Analysis

The memory recovery check failed due to the low baseline:

- Baseline: 14Mi (fresh pod, minimal activity)
- Post-deletion (best): 50Mi (extended, 300s)
- Threshold: 28Mi (2x baseline)
- **Overshoot: 22Mi above threshold**

The operator recovered from 105Mi → 50Mi (a 52% reduction), which is consistent behavior. However, the 2x-baseline threshold is structurally too tight for fresh pods — the ~36Mi residual after deletion represents Go runtime heap retention (MADV_FREE pages not released to the OS), not a true leak.

## Comparison: Cluster B Runs (Same Cluster, Same Operator)

Both runs executed on the same cluster (nodes ip-10-0-13-91 through ip-10-0-84-35) with the same ObO v1.6.0-1181.

| Metric | Run 1 (08/11 17:47) | Run 2 (08/12 11:09) |
|--------|---------------------|---------------------|
| Baseline | 23Mi | 14Mi |
| Post-creation | 106Mi | 105Mi |
| Post-deletion (60s) | 51Mi | 54Mi |
| Post-deletion (ext) | 44Mi | 50Mi |
| Threshold | 46Mi | 28Mi |
| Delta (peak - baseline) | +83Mi | +91Mi |
| Recovery (peak → ext) | -62Mi (58%) | -55Mi (52%) |
| Result | **PASS** | **FAIL** |

### Observations

- **Post-creation memory is identical:** Both runs peak at ~105-106Mi under 600 dashboards — the load behavior is reproducible.
- **Post-deletion residual is consistent:** Both recover to ~44-50Mi. The 6Mi difference is within normal variance.
- **The only difference is baseline:** Run 1 had a warmer pod (23Mi) from prior activity; Run 2 had a freshly-started pod (14Mi). This 9Mi baseline difference causes the threshold to shift from 46Mi (passable) to 28Mi (impossible to meet).
- **The operator is NOT leaking:** If there were a true leak, we'd see post-deletion memory grow between runs. Instead, it's stable at 44-50Mi across both — the Go runtime simply retains a minimum heap size after first allocation.

### Conclusion

The perses-operator memory behavior on Cluster B is healthy and consistent across both runs. The failure in Run 2 is a false positive caused by the 2x-baseline threshold being too strict for pods with baselines below ~25Mi.
